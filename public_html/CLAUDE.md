# CLAUDE.md — Контекст сессии для haramain.online

Этот репозиторий содержит проект **haramain.online** на базе OpenCart 2.3.0.2.4 (opencart.pro).

### КЛЮЧЕВЫЕ ПРАВИЛА ДЛЯ СЕССИИ AI:
1. **Источник истины:** Всегда соблюдай требования из `tech.md`.
2. **Ядро не трогать:** Запрещено вносить изменения в папку `system/`, файлы `config.php`, а также архивные директории `lk/` и `catalog/model-/`.
3. **Строгая ролевая модель:** Выполняй задачи строго из своего файла роли (`DEV_A.md` или `DEV_B.md`).
4. **Не выдумывай типы и поля:** Если в БД не хватает поля для реализации фичи — выдай блок `CONTRACT GAP` с описанием необходимой структуры и остановись.
5. **Валидация:** Все создаваемые или изменяемые PHP-файлы должны быть валидны для PHP 8.x. Проверяй их командой `php -l <file>`.
6. **Язык и стиль:** Используй английский язык для всех сообщений коммитов (Conventional Commits) и комментариев в коде.
