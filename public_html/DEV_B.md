## 2. СПИСОК ЗАДАЧ (Выполнять строго по очереди, 1 PR = 1 задача)

### Задача B1: Отображение цен и валюты SAR
* **Файлы:** `catalog/controller/common/currency.php`, `catalog/view/theme/default/template/product/category.tpl`, `product.tpl`.
* **Что сделать:**
  1. Зафиксировать форматирование цен с суффиксом `риал` / `SAR`.
  2. Проверить корректность вывода цен в карточке товара, каталоге и мини-корзине (`common/cart.tpl`).

### Задача B2: Настройка оформления заказа (Только Мекка и Медина)
* **Файлы:** `extension/module/custom/shipping.php`, `shipping.tpl`, `customer.tpl`.
* **Что сделать:**
  1. В форме оформления заказа сделать поле "Город" выпадающим списком с двумя опциями: `Мекка`, `Медина`.
  2. Скрыть или отключить ввод произвольного адреса города.

### Задача B3: Модуль оплаты "Перевод на карту" + Инструкция и копирование
* **Файлы:** `extension/module/custom/payment.tpl`, `catalog/controller/extension/payment/bank_transfer.php`, `catalog/view/theme/default/template/extension/payment/bank_transfer.tpl`.
* **Что сделать:**
  1. При выборе оплаты "Банковский перевод" выводить блок с инструкцией и реквизитами карт (название банка, номер карты, имя получателя).
  2. Добавить JS-кнопку "Скопировать" рядом с каждым номером карты (копирование в clipboard + toast notification "Номер карты скопирован").
  3. Добавить форму загрузки файла (скриншот/чек перевода `.jpg`, `.png`, `.pdf`).
  4. Сохранять путь загруженного чека в заказ и переводить статус заказа в `Payment Verification` (Проверка чека).

### Задача B4: Отображение чека в админ-панели заказов
* **Файлы:** `admin/controller/sale/order.php`, `admin/view/template/sale/order_info.tpl`.
* **Что сделать:**
  1. В детализации заказа в админке выводить загруженный покупателем чек оплаты.
  2. Предусмотреть кнопки быстрой смены статуса: "Подтвердить оплату" -> `Processing` / "Отклонить" -> `Cancelled`.
